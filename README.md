# AI-Workshop

## Running the site locally

This is a minimal personal website built with Next.js (App Router) and TypeScript.

1. Install [Node.js](https://nodejs.org/) (version 20 or newer).
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`, then open http://localhost:3000

To make a production build, run `npm run build` followed by `npm start`.
